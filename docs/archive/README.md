# Archived project records

These documents are historical records of implementation work and design
decisions. They are retained for context and auditability, but they are not
current build instructions. Use the active documents in `docs/` as the source
for current paths, commands, contracts, and release gates.

Archived groups:

- `superpowers/plans/` - dated implementation plans and delivery checklists.
- `superpowers/specs/` - dated design proposals and acceptance criteria.
- `sdd/` - task briefs, reports, and review artifacts.

Some records intentionally mention superseded `apps/api`, `src/server`, or
legacy styling paths. Do not copy those paths into new work without verifying
the current repository structure.
