# External source research

Use this prompt when the user asks for current information, internet research,
or best-practice guidance for Food Recipes.

## Research question

- Question or decision:
- Why it matters to this repository:
- Relevant existing project contract:
- Required date, version, or ecosystem:

## Instructions

1. Read the relevant Food Recipes rules and current implementation first.
   Define what needs an external source and what can be answered from the
   repository.
2. Browse current primary sources first: official documentation, standards,
   specifications, or original research. Use secondary sources to add
   perspective only when useful.
3. Open the source page and verify that it directly supports the claim.
   Compare its publication or update date with the event or version discussed.
4. Separate:
   - facts verified in this repository;
   - facts supported by external sources;
   - recommendations inferred by applying those facts to this project;
   - decisions that still require the user's choice.
5. Do not adopt advice mechanically. Check compatibility with the existing
   architecture, security rules, package scripts, and user's stated outcome.
   Label optional improvements as optional.
6. Cite claims close to the statement with direct links. For maintained docs,
   include a short source list and the review date.
7. Finish with a concise answer or a reviewable repository patch, whichever the
   user asked for. Do not implement unrelated suggestions.
