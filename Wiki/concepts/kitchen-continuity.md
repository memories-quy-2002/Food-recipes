# Kitchen continuity

The kitchen workflow connects meal planning, shopping, pantry availability,
cooking, history, leftovers, and journaling. Planning can supply ingredients to
shopping; pantry data helps compare availability; sessions preserve progress;
completion creates history. History powers a personal lifetime recap, and each recipe can show the user's own latest cooking memory and journal reflection. Active unchecked shopping items are duplicate-safe
within the signed-in user personal kitchen. Each service owns its API and
validation.
