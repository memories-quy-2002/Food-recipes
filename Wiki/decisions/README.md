# Decision records

Use a decision record for a confirmed choice that affects future product,
architecture, data, API, or security work.

Before adding a record:
1. Check whether it already appears in current code, an API guide, or another record.
2. Record context, chosen option, alternatives, and consequences.
3. Link to affected code and guides.
4. Update the record if the decision changes.

Do not turn an assumption or archived proposal into an approved decision. Use
[the template](./template.md).
